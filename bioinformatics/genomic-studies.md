**Role:** analysis pipeline developer · University of Pennsylvania · 2024 – present\

## The problem

Biobank studies run on billions of genetic variants across millions of participants. At that
scale, an analysis is only useful if it is fast, reproducible, and can be rerun in another
biobank.

## What I built

- **Rare-variant gene-burden and exome-wide association (ExWAS) pipelines** for hearing-loss
  genetics, starting from a replication of an earlier analysis and evolving into a pipeline
  designed to be replicable across biobanks.
- **Pipelines that process multi-terabyte datasets** on HPC and GPU clusters.
- **Machine-learning models** trained on GPU clusters for cardiology studies.

## Stack

Python · HPC/GPU clusters · ML
