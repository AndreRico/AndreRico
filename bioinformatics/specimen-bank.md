**Role:** database architect and developer · University of Pennsylvania · 2024 – present\

## The problem

A national organ and specimen bank needs to track every transaction across many functions,
with the reliability, security and documentation expected of research infrastructure.

## What I built

- **The SQL database architecture** supporting the system's transaction functions.
- **Secure cloud deployment** on AWS, working with Penn's cloud team.
- **Supporting documentation:** data and process models, metadata, user manuals and regulatory
  documentation.
